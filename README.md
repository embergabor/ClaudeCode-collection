# ClaudeCode collection

Projects built with Claude Code.

## Mac apps

| Project | Description | Visibility |
|---|---|---|
| [gog-disc-archiver](https://github.com/embergabor/gog-disc-archiver) | Burn GOG game installers to data Blu-ray/DVD on macOS, verify them, keep a catalogue and print case covers. | Public |
| [film-companion](https://github.com/embergabor/film-companion) | macOS app for the workflow around scanning developed 35 mm film: strips, scans, contact sheets, binders. | Public |

## Steam Deck

| Project | Description | Visibility |
|---|---|---|
| [deck-gog-installer](https://github.com/embergabor/deck-gog-installer) | Gamepad-first Steam Deck app that runs GOG installers from a server under Proton. | Private |
| [wavesafe-deck-plugin](https://github.com/embergabor/wavesafe-deck-plugin) | WaveSafe for Steam Deck: a fully offline music player for your own library, controlled from the Quick Access Menu while you game. | Public |
